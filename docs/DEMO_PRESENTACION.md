# Demostración de Astro‑Trazos

Abre `dist/Astro-Trazos-Presentacion.html` en Chrome o Edge y usa pantalla completa. También puedes abrir la versión de desarrollo en `http://127.0.0.1:5173/` cuando Vite esté activo.

1. En el menú muestra que los seis mapas de las tarjetas están iluminados y sin candados. **Jugar** abre Despegue; también puedes elegir cualquier tarjeta.
2. En Despegue, pulsa **Ver ejemplo**. Un trazado dorado enseña los dos segmentos que rodean el cometa. Ocúltalo y dibuja tu propia ruta. Al soltar el pincel, Nilo prueba la construcción. Si toca el cometa, la escena lo muestra.
3. Abre **El peso justo** desde el menú. Pulsa **Ver ejemplo** y observa el rectángulo de 40 u × 30 u. Arrastra desde una esquina hasta la opuesta: el juego construye el rectángulo en pasos de 5 u. Base, altura y su producto aparecen mientras lo cambias, y la balanza reacciona al área final.
4. Abre **Bloquea los rayos**. La pista enseña dónde pueden cruzarse las defensas con los tres rayos. Dibuja otros cruces para ver que cada láser se detiene en la intersección real.
5. Si hay tiempo, enseña **Polígonos lejanos** y **Núcleo cósmico**: la pista dibuja el hexágono y la órbita sin consumir tinta.

Las pistas son opcionales y se pueden ocultar. El jugador completa los niveles con sus propios trazos. Para verificar el proyecto: `npm run lint`, `npm test` y `npm run standalone`.
