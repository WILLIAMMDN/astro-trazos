# Diseño de niveles

| Etapa | Mecánica | Concepto demostrable |
|---|---|---|
| Tutorial | Dibujar un segmento | coordenadas, longitud, vector |
| Nivel 1 | Crear un puente | colisión + consumo de tinta |
| Nivel 2 | Crear una rampa | ángulo + rotación + gravedad |
| Nivel 3 | Activar un peso | polígono + área shoelace |
| Nivel 4 | Bloquear rayos | intersección de segmentos + clipping |
| Nivel 5 | Reparar la nave | composición de técnicas |

Cada nivel debe poder demostrarse con el modo académico activado.
