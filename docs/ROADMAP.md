# Roadmap

## MVP académico
- Game loop estable.
- Matrices 3x3: traslación, rotación, escala y composición.
- Cohen–Sutherland para líneas.
- AABB y segmento–segmento.
- Dibujo con mouse.
- Tinta por longitud.
- Física simple: velocidad, gravedad e integración por delta time.
- Tutorial + 2 niveles.
- Modo debug académico.

## Versión final
- Tutorial + 5 niveles.
- Área por fórmula de Gauss (shoelace).
- Láseres por intersección de segmentos.
- Parallax y partículas.
- UI final, audio y accesibilidad básica.
- Pruebas, manuales, capturas y demo.

## Orden de prioridad
1. Algoritmos exigidos.
2. Gameplay estable.
3. Niveles.
4. Pruebas y Lab 05.
5. Pulido visual/audio.
